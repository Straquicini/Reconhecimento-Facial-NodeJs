# 🔐 Sistema de Reconhecimento Facial

## 📖 Descrição

Este projeto consiste no desenvolvimento de um **Sistema de Reconhecimento Facial** utilizando tecnologias web.

A aplicação permite utilizar a câmara do dispositivo para realizar a captura facial, processar os dados necessários para o reconhecimento e armazenar as informações do sistema através do **Supabase**.

O projeto utiliza **HTML, CSS e JavaScript** no frontend e **Node.js** para o ambiente de execução e gestão das dependências.

---

## 🎯 Objetivo do projeto

O principal objetivo é desenvolver uma aplicação web capaz de utilizar **reconhecimento facial** para identificar ou verificar utilizadores previamente registados.

---

# ⚙️ Funcionalidades

## 👤 Registo de utilizadores

A aplicação permite realizar o registo de utilizadores no sistema.

Durante o processo podem ser recolhidos dados como:

* Nome do utilizador;
* Imagem facial;
* Dados necessários para o reconhecimento.

As informações são posteriormente armazenadas no Supabase.

---

## 📷 Captura facial

O sistema utiliza a câmara do dispositivo para realizar a captura da imagem.

O navegador solicita ao utilizador autorização para aceder à câmara.

Fluxo da captura:

```text
Utilizador
    │
    ▼
Permissão da câmara
    │
    ▼
Acesso à Webcam
    │
    ▼
Captura da imagem
    │
    ▼
Processamento facial
```
